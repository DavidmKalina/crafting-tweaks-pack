# Crafting Tweaks datapack

Hosting for the CraftingTweaks Paper plugin (Minecraft 26.3):

- `ctweaks-datapack.zip`: stonecutter recipes (building pieces, logs to planks, recolouring, extra slabs and stairs).
  The plugin fetches it into the world's `datapacks` folder.

It's generated by the plugin project's `tools/generate.py`; don't edit it by hand. The models of the extra slabs and
stairs are in the server's resource pack (github.com/DavidmKalina/resource-pack), no longer here.
