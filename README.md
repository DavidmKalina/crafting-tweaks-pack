# Crafting Tweaks packs

Hosting for the CraftingTweaks Paper plugin (Minecraft 26.3):

- `ctweaks-datapack.zip`: stonecutter recipes (building pieces, logs to planks, recolouring, extra slabs and stairs).
  The plugin fetches it into the world's `datapacks` folder.
- `ctweaks-pack.zip`: resource pack (pack format 97) with the models of the extra slabs and stairs.
  Players are offered it when they join.

Both are generated by the plugin project's `tools/generate.py`; don't edit them by hand.
